# Jost Medium

The runtime text face (tooltips, readouts, menus, preset names), embedded
by `silkscreen-text` as `JOST_MEDIUM`. Build scripts can letter faceplates
in it too: `Faceplate::font_dir(silkscreen_build::TEXT_FONT_DIR)`.

- Source: https://github.com/indestructible-type/Jost (v3.5, `fonts/ttf`),
  fetched 2026-10-17.
